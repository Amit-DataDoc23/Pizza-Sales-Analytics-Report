# 🍕 Pizza Sales Analytics Dashboard

## 📌 Overview
This Power BI dashboard provides a **comprehensive analysis of pizza sales for 2015**.  
It highlights performance across categories, sizes, time periods, and individual products.

## 📊 Sales Insights

### 🗓️ Time Trends
- **Busiest Days:** Friday & Saturday evenings  
- **Peak Months:** January & July  

### 🍕 Category Performance
- **Top Category:** Classic Pizza → highest revenue & sales  
- **Top Size:** Large Pizza → 45.89% revenue share  

### 🏆 Best Sellers
- **Revenue:** Thai Chicken Pizza ($43K)  
- **Quantity & Orders:** Classic Deluxe Pizza (2.5K sold, 2.3K orders)  

### ❌ Worst Sellers
- **Revenue, Quantity & Orders:** Brie Carre Pizza (lowest contribution, ~490 orders)
